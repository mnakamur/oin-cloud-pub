# 押印クラウドとは?

[EN](README.md)

押印クラウド(https://www.oin-cloud.com)はPDF文書を署名者に送付し電子署名とタイムスタンプを付与します。<br/>
また、テキスト入力や押印画像、日付、署名描画を追加したのち、 電子署名をつけることも可能です。<br/>

現状では"試験的”な電子署名クラウドサイトとなります。<br/>
試験的と記載している理由は、下記 2 点です。<br/> 1.署名に使われる電子証明書は,OPENSSL+AWS KMS で作られた self-sign 証明書となっています<br/> 2.タイムスタンプについても　オープンソースのタイムススタンプ(https://freetsa.org/index_en.php)を利用しています<br/> \*そのため、署名した文書を Adobe 　 Reader で見ると、”署名の完全性は不明です"と出てきます。<br/>
当メッセージを消したい場合には、クライアント側で<br/>
署名のプロパティ表示 → 署名者の証明書を表示 →"信頼"タグ選択 → 信頼済み証明書に追加<br/>
を行ってください

## 現状登録できる PDF 仕様<br/>

### 下記の文書は現状では登録できません <br/>

１．PDF 以外の文書<br/>
２．パスワードで保護されている文書<br/>
３．すでに署名されている文書<br/>
４．２ＭＢを超える文書<br/>
５．フォームが設定されている文書<br/>
６．最新の Adobe acrobat で出力・加工した文書<br/>
　　（\*PDF の V1.5 以降の新機能ベースでの文書は残念ながら現状では登録できません<br/>
　　　その他の PDF 編集ソフト：PDFElement 等で出力された文書も登録できません）<br/>

### 登録できる文書<br/>

１．WORD,EXCEL 等で作った文書を PDF にする際に、エクスポートを選択し<br/>
　　 PDF/XSP ドキュメントの作成にて PDF を作成して頂ければ登録可能です<br/>
２　 OpenOffice,LibreOffice で出力された PDF は登録可能です。<br/>

# 押印クラウドの使い方

１．アカウント作成<br/>
文書を登録して、署名依頼するにはアカウント登録が必要です。メールアドレス＋パスワードでアカウント登録を行えます<br/>
登録されたメールアドレスに認証コードが送られますので、コード入力すれば登録完了です<br/>

２．プロフィール編集<br/>
お名前、会社名等を登録します（登録すると会社名+名前で文書回送されます）<br/>

３．ＰＤＦ文書登録<br/>
署名対象の文書を登録します。文書は PDF のみです。ファイルの大きさは 2MB までです。<br/>
登録できる文書は署名する 1 文書のみで添付文書等は追加できません。<br/>

４．署名回送ルートの作成<br/>
文書を署名してもらう相手先を追加します。<br/>
それぞれの相手先の名前、メールアドレス、署名属性（署名時の入力有無）を設定します。<br/>

５．署名時入力設定<br/>
署名時に、テキスト文字列や印影、署名日付等設定がある場合に使います<br/>
回送ルート保存後、入力対象ページにボタンクリックと、ドラッグ＆ドロップで入力位置・領域を指定、入力依頼内容を記載します<br/>
署名者それぞれに複数個設定できます。<br/>

６．署名文書の回送<br/>
文書を回送します。署名は設定したルートに従って順に回送されます<br/>

７．文書の確認・入力・署名<br/>
メールアドレスに押印クラウドからの署名メールが届きます<br/>
メール内にあるリンクをクリックすることにより署名文書が開きます<br/>
内容を確認し、入力ある場合には入力、署名します<br/>
リンクは送付後 7 日間有効です<br/>

８．文書の却下<br/>
内容に不備等ある場合には、理由を記載し却下できます。却下されたメールは、文書作成者に送られます。<br/>

９．文書署名の完了<br/>
すべての署名者の署名が完了すると、ルート全員に署名完了メールが送られます<br/>
リンクをクリックすることにより署名文書が開きます。<br/>
リンクは完了メール送付後 7 日間は有効です。署名文書はダウンロードして保存してください<br/>

## 付与される電子署名について

付与される電子署名は、署名タイムスタンプ付署名（PAdES-T）レベルです.<br/>

文書に対する署名の形式は、PAdES-Basic ベース（adbe.pkcs7.detached）、 ハッシュアルゴリズム sha512,署名アルゴリズム RSA 　 PKCS#1 　 V1.5 を利用しています。<br/>
タイムスタンプについては、DocTimeStamp 形式で、ハッシュアルゴリズムと署名アルゴリズムは 文書への署名と同じです。<br/>
